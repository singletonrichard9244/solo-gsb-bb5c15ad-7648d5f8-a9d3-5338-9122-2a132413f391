方案比选目标（单张试排按三种策略分别排样后择优）

同一输入分别按 面积降序 / 最长边降序 / 宽高差降序 三种确定性策略排样（断头台、刀缝、旋转与纹向规则一致）： 「优先多排」依次按已排件数、已排面积、刀数少、策略顺序择优； 「优先省刀」排除空方案后依次按刀数少、已排面积、已排件数、策略顺序择优。 全部排不进时不指定最佳方案。

开启后，批量每轮分别试排各未完成订单，按本张已排面积、件数、录入顺序选订单； 多纸型每轮联合比较「订单 × 纸型」候选，仍按单位已排面积成本、件数、录入顺序决胜， 选中后只扣减该订单与该纸型库存。任一剩余订单在所有可用纸型均无进展时返回受阻订单，不生成空白纸、不误扣库存。 未填写订单号的行视为同组且不影响其他订单。

勾选后，以每种成品的每套用量（成品表新增列）按比例组成完整套； 服务端每张纸都用现有断头台 / 刀缝 / 纹向规则试排，选择完整套数最多的布局： 批量模式逐张扣减直到做满计划套数；多纸型模式同套数下再按单位已排面积成本、件数、录入顺序选纸。 剩余材料组不成一整套即 no-progress，本轮不扣库存。成套与订单隔离不能同时开启。

按当前规则逐张排样；全部排完、达到用纸上限，或某张纸排不进任何成品时停止（无进展立即止损，不生成空白纸）。

录入 2～8 种候选纸张（单价须大于 0、张数为 0～500 整数；纹向为沿宽/沿高）。每轮对有库存且放得下余件的纸型试排 （只采用纸张纹向与成品要求平行的朝向），按 单位已排成品面积成本最低，同分比已排件数，再同分按录入顺序选出下一张；空白纸不计入结果。

排料结果

叠纸裁切排程

复用当前批量 / 多纸型排产结果，把各张纸的断头台切割树合成可执行刀次： 仅当待切区域宽高、刀向、刀位、刀缝一致时合并，每批不超过叠纸上限； 子刀必须等所在纸张的父刀完成后才可入批。每轮优先合并张数最多、再按总切线长度、纸张序号与原刀序决胜。

执行工单（按班次容量拆分刀次）

按父刀依赖做稳定拓扑拆分：父刀必在同刀/早班完成，就绪刀次按排程批次先后分班， 不拆散批次、也不打乱批次内纸张顺序；每批叠纸超过「每批最多纸张」的刀标记为未分配， 跨班才能完成的父子刀在「跨班次依赖」表中列出。可导出 JSON 或 CSV 下发车间。

裁切抽检计划（选纸覆盖全部已分配刀次）

把每个已分配全局刀次视为必须覆盖目标：抽中一张纸即同时覆盖该纸参与的全部刀次。 逐轮按新增覆盖刀次最多 → 该纸参与刀次总数多 → 纸张序号小选纸，达到上限或覆盖完成即止。 未分配刀单列提示，不计入覆盖率分母。

填写左侧参数后点击「生成裁切方案」

余料库存登记（把本次排料结果的余料区入库复用）

将每张纸 layout.frees 的余料矩形标准化入库：保留纸型、纸张纹向、刀缝、纸面坐标、尺寸与来源批次（含轮次/纸型/订单号）。 同批次重复登记相同余料会自动跳过。登记后可在「余料库存与复用」页查询并按成品需求预占。

余料录入

手工录入切下后留存的余料（尺寸、纸型纹向与刀缝随记录保留）；排料结果中的余料可在「裁切试排」页一键登记。

复用预占（按成品需求原子占用余料）

给定成品宽高、数量与纹向要求：仅在可用余料中按旋转 / 纹向可行性筛选， 以占用后剩余面积最小确定性择优（平局再比余料面积、短边、长边、不旋转、录入先后）。 一次请求预占足量余料；库存不足时不会扣减任何记录，并返回缺口明细（尺寸不足 / 纹向受限）。
